# Amira Mahmedjan — personal website

Single-page React + Vite site. Feed the pixel-art me a matcha from the shelves on the home page.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build to dist/
npm test
npm run lint
```

Content lives in plain arrays at the top of each component in `src/components/` (projects in `src/data/projects.js`). Sprite frames are in `src/assets/`; the sheets they were cropped from are in `art/`.
